# 账号、个人中心与支持者功能

2026-10-25；仅部署到独立站 appgap.if2.ai。保留原 AppGap、mybros 与 Mini Tanks 服务。

## 使用入口

- `/register`：用户名 3–24 位、密码 8–128 字符，昵称可选。不收集邮箱，不假装已经验证邮箱。注册后仅展示一次恢复码；恢复账号或修改密码后生成新码并撤销原账号会话。
- `/login`：账号登录、恢复账号、管理员入口。管理员沿用已有站点口令；普通用户注册不能获得管理员角色。管理员切换登录会清除浏览器里的普通账号 Cookie。
- `/account`：个人资料、App Store / Steam 候选与立项统计、近期研究、支持记录及公开偏好、修改密码和退出全部账号会话。
- `/support`：支付宝码、支持登记、累计榜、近期留言；管理员另见到账核对。此页和公共支持动态允许未登录阅读，研究数据仍需登录。

原 `pools` 完整保留，迁移 `0008_community.sql` 复制到 `user_pools` 并归属固定 `owner` 管理员。新账号与新浏览器不会自动导入别人的旧 localStorage 收藏。回滚旧版本时旧表仍可用，新账号数据不删除。

## 安全与数据归属

密码使用 Node 24 的异步 scrypt：N=131072、r=8、p=1、每次独立 16 字节盐；最多同时处理两份密码派生，避免撑满 VPS。会话和恢复码均为 32 字节随机值，只存 SHA256，原始值不写日志。Cookie 为 HttpOnly / SameSite=Lax，HTTPS 使用 Secure；服务端校验有效期，账号会话支持撤销。管理员历史口令会话仍按原 30 天签名校验，跨设备全部失效需在服务器更换口令。

注册、登录、恢复和改密码有数据库持久化的 IP / 用户名限速；过去 24 小时最多 100 个新账号。写操作拒绝跨站来源，身份接口要求 JSON。收藏、私人研究、支持记录按真实账号 ID 授权。私人报告的新缓存键不再依赖某一个浏览器会话；同账号跨设备可复用，不同账号不能读取。

标准报告仍共享 7 天；私人研究仍为 24 小时，不因注册永久保留。最近研究最多记录 200 个索引，个人中心展示最近 30 条；过期报告不能通过详情 API 读取。旧匿名浏览器研究不自动认领。每账号每天最多 5 次新 AI 请求，全站仍限 20 次（香港日）；共享结果的读取不扣额度。修改密码或退出设备不会销毁账号下的私人报告。

## 支付宝支持流程

1. 用户登录后登记金额、展示昵称、可选留言与公开偏好，得到唯一登记编号；默认不公开。
2. 用支付宝扫描作者提供的码，在付款备注填写登记编号。登记本身不执行扣款，也不会标记成功。
3. 管理员在真实支付宝账单核对后，输入实际到账金额和唯一流水号确认；一笔流水只能入账一次，重复提交不重复计入。
4. 只有 `confirmed` 且用户同意公开的记录进入累计榜和顶部循环动态。取消公开会同时从两处移除；私密支持仍计入站点的匿名总额。
5. 退款须先在支付渠道完成，再在站内标为全额退款；该记录随即不再进入累计额。站内按钮不执行支付或退款。目前不支持部分退款。

只支持 CNY，以整数分记账，金额 ¥1–100,000，拒绝科学计数和多于两位小数。支持记录每用户最多三笔待确认，并限制提交频率。用户可随时在个人中心关闭公开展示。

顶部动态每 30 秒刷新数据，CSS 连续循环；鼠标悬停、键盘焦点和暂停按钮均可暂停，点击进入支持页面。尊重 `prefers-reduced-motion`，没有真实公开记录时显示空状态，不伪造支持者或金额。

## 运维

- 支付宝码保存在 `/var/lib/appgap/donations/qr.png`，不进公开源码仓库；由 `/api/donations/qr` 读取固定路径，仅允许不超过 2 MiB 的 PNG。图片来自作者指定的本机文件，原样复制，不重绘。
- 现有站点备份包含账号、会话哈希、私人缓存和支持记录；新增保存收款码副本。备份仍保留 30 天，因此在线缓存过期不是备份物理删除承诺。
- 原表不删除，发布前先做在线备份并核对原收藏数量。仅重启 AppGap，原隧道和游戏服务保持。
- 不能仅靠静态收款码开启官方自动回调；正式接入方案见 [payment-options.md](payment-options.md)。
