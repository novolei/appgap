# AI 结果缓存与预算

2026-10-25。App Store 与 Steam 共用 `worker/analysis-cache.ts`，SQLite 表 `ai_result_cache` / `ai_call_ledger`，迁移 `0007_ai_cache.sql`。现有 `ai_analyses` 只用于兼容旧结果，不删除原缓存。

- 标准公开数据的分析缓存 7 天；独立 Node 站已启用注册账号，自定义文字筛选、问题或资料按账号隔离、缓存 24 小时，不进入共享查询。同账号换设备仍可复用，个人中心可查看尚未过期的研究。旧 Workers 模式继续使用签名研究会话，不将旧匿名资料自动认领到新账号。
- Steam 键覆盖快照 SHA256、分析版本、提示词版本、模型和规范化筛选。App Store 键覆盖应用、成功采集批次、应用更新时间、模型和提示词版本。修改提示词或统计口径时更新相应版本，避免错误复用。
- 读取缓存不调用模型；相同请求并发合并。一个 SQLite 数据库对应一个进程内缓存协调器；唯一运行索引防止跨进程重复调用。多实例的相同请求会得到繁忙响应，需要实际部署队列后才能跨进程等待。
- App Store `fresh=1` 不再绕过有效结果。页面加载详情自动读已有结果；新数据时可以按需更新。Steam 页面自动 GET `/api/steam/analysis`，不会因打开页面付费。
- 全站每日 20 次新请求，香港时间重置；账号另限 5 次（含 App Store / Steam 及私人研究），失败也计数。共享缓存的归属与调用额度的付款方分开：新生成计入发起账号，其他账号读取不扣额度。额度存在数据库，重启不重置，超限仍可读缓存；此上限仍不是美元硬预算。
- 用户问题 / 资料只通过 POST，最长 400 / 1500 字；模型输入最多 128 KiB、输出最多 8,000 tokens，85 秒超时，截断结果不缓存。当前没有自动联网检索或用户 URL 抓取。上游错误正文不进入日志，日志仅保留模型与 token 用量等元信息。
- 过期内容在新生成时清理，读取时始终检查有效期；预算流水保留 30 天。主库备份仍保留 30 天，在线缓存失效不等于备份中的物理删除。

账号、支持者累计榜、支付宝收款码与人工核对已在独立站启用，详见 [community.md](community.md)。支付宝官方自动回调尚未接入；原站与其访问口令不变。
